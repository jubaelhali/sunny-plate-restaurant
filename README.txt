SUNNY PLATE RESTAURANT — POLISHED BEGINNER PROJECT

Technologies: HTML, CSS, Python (Flask), JSON API, PWA manifest and service worker.

Run locally:
1. Install Python.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000

Install as a web app:
Host this project on an HTTPS web host, then open it in a supported browser.
On Android Chrome, use the browser menu > Install app or Add to Home screen.
This is a PWA, not an Android APK.

The restaurant name, phone, email, address and menu are sample content. Edit them before presenting.
Some food photography loads from Unsplash and needs an internet connection.
This is a student portfolio practice project, not a production restaurant ordering system.
